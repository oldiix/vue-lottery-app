# Vue Lottery App

Лабораторна робота №4. Застосунок-лотерея на Vue 3 + TypeScript (Composition API), Bootstrap (SCSS).

## Функціональність

- реєстрація учасників з валідацією (email, телефон `+380XXXXXXXXX`, дата народження)
- випадковий вибір до трьох переможців
- редагування та видалення учасників у модальних вікнах
- пошук за іменем та сортування за іменем і датою народження
- збереження учасників у localStorage

## Запуск

```bash
npm install
npm run dev
```
